# K.L.P. College portal refresh and admissions answers

## Outcome
Keep every existing page, document viewer, programme comparison, notice filter and question assistant working. Refresh the presentation around the selected **Heritage Modern Excellence** direction: an editorial, image-led college site with stronger quick-access links, royal blue, navy and warm gold. Use the real college crest and campus imagery, not the prototype’s placeholders or invented copy.

## What will change
1. **Admissions answers:** Give the assistant a dedicated, source-linked admission brief from the saved official 2026–27 notice and programme instructions. Make it distinguish current admission steps, the state application link, college desk assistance and query numbers from older programme-specific eligibility or duration. If an exact current criterion is not published, it must say so.
2. **Shared design:** Replace the current green-leaning palette with the chosen royal-blue/navy/gold/off-white tokens; use Plus Jakarta Sans for headings and Inter for body text. Carry consistent cards, buttons, spacious typography, readable dark mode and accessible contrast across existing routes.
3. **Header and first screen:** Make the existing navigation a sticky translucent header that tightens on scroll, with a visible Admission action and working keyboard/mobile menus. Keep the real campus photo as the full-width homepage background, the college name as the main heading, and prominent Apply Now / Explore Courses actions. Put verified notice links in a gently moving strip below it. Rework the link grid with better spacing and premium icons.
4. **Homepage and supporting pages:** Preserve all existing text and sections while improving the editorial layout. Add practical Students, Teachers and Admin quick paths to existing information (without inventing an admin dashboard); verified count-up figures only for facts that can be established (e.g. founding year and listed programmes). Improve programme, faculty-directory and gallery presentation; use available real images and an accessible lightbox where images exist. Do not invent staff portraits, testimonials, student counts, social profiles or a map location. If no verified testimonials are available, omit the carousel rather than fabricate quotes.
5. **Motion and utilities:** Use Framer Motion for restrained reveal, hover and route transitions; provide reduced-motion fallbacks. Add a compact crest loading state where a page actually waits, a theme switch, scroll progress and back-to-top control. Keep the existing question launcher and provide an admissions enquiry path using the existing assistant/contact information; only add WhatsApp if an official WhatsApp number/link is verified.
6. **Quality pass:** Test the homepage and all existing routes at desktop, tablet and phone widths, including navigation, menus, images, document links, theme persistence, lightbox, admissions answers, keyboard focus and reduced motion. Resolve any new layout or console errors without deleting content.

## Technical notes
- Existing source-of-truth college facts and outbound official links remain in `src/lib/college.ts`. Admission grounding stays server-side beside the official snapshot in `src/lib/official.server.ts`; no unverified data is introduced.
- Extend the existing shared SiteLayout and page styles rather than replacing routes. Preserve page-specific metadata through the existing SEO helper.
- The chosen prototype guides the layout and emphasis, not its false phone/email, outdated admission year, made-up numbers or serif typography.
