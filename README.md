Build a modern, production-quality website for Kishan Lal Public College (K.L.P. College, Rewari - https://www.klpcollege.ac.in/).

Do NOT redesign it randomly.

Fix every issue you find in:
- spacing
- typography
- responsive behavior
- navigation
- dropdowns
- mobile menu
- card consistency
- button consistency
- image ratios
- section hierarchy
- accessibility
- SEO
- loading states
- empty states
- error handling
- broken routes
- console errors

Make the UI feel more premium, less template-like, and more like a professionally designed modern Indian university website.
Check every route on desktop and mobile.
Remove duplicated code and inconsistent styling.
Do not invent institutional facts.
Finish with a complete production-quality pass.
